# Richa Singh Portfolio

## ML Studio page added

The portfolio now includes a separate **ML Studio** page. The homepage navigation contains an `ML Studio` tab that opens `ml-studio.html`. The new page has its own stylesheet and navigation script under `assets/`, so the existing homepage styling and JavaScript remain unchanged.

## Publish with GitHub Pages

1. Upload/replace the files in this repository with the contents of this folder, preserving the folder structure.
2. Commit the changes to the branch configured for GitHub Pages (commonly `main`).
3. Open the published homepage and select **ML Studio** in the navigation.

The homepage remains `index.html`; the new page links back to it.
