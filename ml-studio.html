Project overview

From raw data to evaluated models—through a GUI.

The project is designed to make common machine learning workflows easier to learn, demonstrate and reproduce. Users can work with their own tabular datasets or explore built-in datasets, then select an algorithm and inspect its results.

Project objective

To provide an accessible learning and experimentation environment that reduces repetitive coding in introductory ML workflows while keeping the underlying Python tools visible and extensible.

Who can use it?

  • B.Tech and postgraduate students learning machine learning
  • Educators demonstrating algorithms and evaluation metrics
  • Researchers exploring baseline models on structured datasets
  • Python learners practising the end-to-end ML pipeline
Core capabilities

One interface, multiple ML tasks.

The notebook groups the main stages of a typical machine learning experiment into clear GUI sections.

📂

Dataset loading

Import CSV and Excel files or start with sample datasets such as Iris, Wine, Breast Cancer and Diabetes.

🔎

Data exploration

Inspect dataset dimensions, column types, missing values, duplicates and descriptive statistics.

🧹

Preprocessing

Clean duplicate or incomplete rows, impute missing feature values, encode categories and scale numeric features.

🧠

Classification & regression

Train a selection of supervised learning algorithms for categorical and numeric prediction tasks.

🧩

Clustering

Explore unsupervised grouping with K-Means, DBSCAN and Agglomerative Clustering, with a PCA projection.

📊

Evaluation & comparison

Review metrics, confusion matrices, classification reports, actual-versus-predicted plots and baseline comparisons.

🎯

Feature insights

Use permutation importance to estimate how much individual input columns contribute to model performance.

🔮

New predictions

Enter a new observation as JSON and use the fitted pipeline to generate a prediction.

💾

Model & result export

Save the trained pipeline as a Joblib file and export held-out test predictions to CSV.

How it works

A guided machine learning workflow.

The user moves through the stages below using the notebook's interactive tabs.

Upload a CSV/Excel dataset or select a sample dataset.

Explore & prepare

Train & compare

Choose a task and algorithm, then fit and compare models.

Evaluate & export

Inspect metrics and visualizations, make predictions and save outputs.

Run the project

Getting started.

Open the notebook in Jupyter Notebook, JupyterLab or Google Colab. Run the setup cell, then execute the notebook cells in order to display the interface.

# Install dependencies
%pip install pandas numpy matplotlib seaborn scikit-learn ipywidgets joblib openpyxl

# Then run the notebook cells from top to bottom

The GUI relies on notebook widget support. If widgets do not appear, check that ipywidgets is installed and enabled in your notebook environment.

Future enhancements

Potential next steps.

The current notebook is an educational prototype. The following features could expand it into a more complete research workbench.

AutoML & tuning

Automated model selection, cross-validation and hyperparameter optimization.

Explainable AI

SHAP explanations and local explanations for individual predictions.

Advanced analytics

Feature selection, association rules, anomaly detection and imbalance handling.

Deep learning

Neural network workflows using TensorFlow or PyTorch.

Experiment tracking

Save experiment configurations, metrics, timestamps and model versions.

Web application

Move from notebook widgets to a standalone Streamlit or Flask interface.

Project note ML Studio is inspired by the workflow of WEKA, but it is an independently developed educational prototype—not an official WEKA product or a complete replacement. Model scores depend on the dataset, target selection, preprocessing and validation strategy.
